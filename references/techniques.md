<a id="oars"></a>
## 1. OARS：动机式访谈的四项核心技术

MI（Motivational Interviewing）把所有访谈技巧归为四类，在不同场景里反复运用，区别只是占比。这是你可以随身带的四件工具。

### O — 开放式问题（Open-ended questions）
用"如何 / 什么 / 什么时候 / 告诉我…… / 描述一下……"开场，不限定答案范围。功能：激发深入表达、捕捉细节与情感。
- 封闭式（"是否/有无"）只在**确认事实**时用，比如"这段关系是六月结束的，对吗？"。探索时一律开放式。

### A — 肯定（Affirmations）
真诚地认可用户的努力、处境或觉察，而不是空泛夸奖。
- ❌ "你真棒、你成长了"
- ✅ "你能意识到自己在表达上的克制，这本身就需要不少自我观察。"
作用：降低防御，让人愿意继续往深里说。

### R — 反射性倾听（Reflections）
把用户说的话，用你自己的话"像镜子一样"映回去——不是为了复述，而是为了让他听见自己，常常能引出更深的修正。
- 用户："那段时间我就是不想说话。"
- 反射："听起来那种沉默不全是没话说，更像是一种……保护？"（留个尾巴让他纠正或确认）
反射性倾听是处理"用户防御/情绪化"时最有效的单一技术。

#### 重新命名（Renaming）：反射性倾听的主动变体

普通反射"照原样映回去"，重新命名往前多走半步——**把用户反复绕着的模糊词，递回一个更精准的名字**。它比反射主动，又比"替用户下定义"克制：你是把一个更锋利的词递到他手里，认不认由他。

- 用户反复说"我就是想太多" → "你说的'想太多'，是不是其实一直在反复预演最坏情况？"
- 用户说"我跟谁都不太亲近" → "这种'不亲近'，更像主动保持距离，还是想靠近但不知道怎么开口？"

为什么有用：用户卡住常常不是没东西可说，而是手里没有够准的词抓住自己的感受。一个更准的命名能一下子解锁一大段表达。命名之后把解释权还给他——他否认也没关系，否认里常常藏着更准的命名。

#### 言行落差：用一个旁观者的视角照出自欺

人回看自己时也会事后合理化——嘴上说在乎 A，可你看他做的事，一直在围着 B 转。直接说"你其实在追求 B"是贴标签（违反原则 1）；但你可以借一个**旁观者的视角**把这个落差递回去，让他自己看见：

- "你说这半年最看重'自由'——可如果有个陌生人只看你的日程表和花销、不听你说话，他会觉得你最在乎的是什么？"
- "你说那阵子一直在争取 X，可那段时间你做的多数决定，好像都在避免 Y。X 和 Y，哪个更像是你真正在守的？"

为什么有用：事后合理化是回顾型访谈里最大的干扰——用户会用"我当时是为了……"把行为重新讲圆。引入"只看行为、不听话的旁观者"，能温和地撬开这层包装，又不下判断。答案仍由他给：那个旁观者看到的东西，他认不认、怎么解释，都是往下深的入口。

#### "应该" vs "真正想要"：撬开被"应该"绑架的表述

人回看自己时还有种更隐蔽的自欺——说出来的不是真实感受，而是"听起来正确的、应该的"话。"我那时应该高兴才对""按理说我该知足""大家都觉得我混得不错"。这些"应该"句式不是感受，是套了个外部标准。听到"应该 / 按理 / 大家都"，可以温和地递回：

- "你说'应该高兴'——先把'应该'放一边，你当时真正的心情是什么？"
- "如果不拿'大家怎么看'来衡量，你自己觉得那段日子过得怎么样？"

为什么有用：回顾型访谈里，用户常被"应该"绑架，用正确答案替代真实感受。把这层"应该"轻轻揭一下，真实情绪才有空间浮上来。它和"言行落差"是一对——言行落差戳的是"嘴上 vs 行为"，这个戳的是"应该 vs 真心"，两个维度互补。同样递回、不判定。

### S — 总结（Summaries）
阶段性把一段对话收拢成几句话，给用户一个"被完整听见"的感觉，也给自己一个查漏的机会。常用在换主题、或用户讲了一大段需要梳理时。

> 关键洞察：不同的人需要的不是不同的技巧，而是这同一组技巧（OARS）的不同配比。面对不善表达的用户，反射性倾听和肯定的占比要高；面对善于表达的用户，开放式问题和总结的占比可以高。

<a id="六法"></a>
## 2. 六种提问法及适用场景

洪敬谱从新闻采访实践提炼的六法，附上"什么时候用哪种"：

| 方法 | 怎么做 | 适用场景 |
|---|---|---|
| 开门见山法 | 直入核心议题 | 时间紧 / 用户对话题很熟 |
| 迂回启发法 | 从外围逐步引向核心 | 用户偏内向 / 需要深挖内心想法 |
| 抛砖引玉法 | 先用浅显问题当引子再深入 | 用户拘谨、不自信、不知从何说起 |
| 恰当验证法 | 对已获取的信息核实补充 | 确认你理解对了、查漏补缺 |
| 粗细结合法 | 宏观框架与微观细节并行 | 兼顾全局与深度 |

**自我采访里最常用的是迂回启发、抛砖引玉、恰当验证、粗细结合。** 不用激将刺激法——你面对的是用户自己，"激将"容易变成自我批评的放大器；除非用户主动带着"我想被挑战一下"的态度来。

<a id="沉默"></a>
## 3. 沉默策略：数到七

沉默是循证基础最强的单项技术（实验心理学 + 跨文化研究全链路打通）。

- **实验数据**：美国文化语境下，对话中 4 秒沉默就会引发显著不适；日本说话者对 8.2 秒沉默仍感舒适。中文语境的阈值大概介于两者之间。
- **"数到七"操作法**（NN/g 的 Kaplan 提出）：用户答完一个重要问题后，**在心里默数到七再开口**。前 4 秒不适感达到峰值（你要忍住别填话），后 3 秒给他整理思绪的空间。他往往会在这几秒里补充出更深一层的想法。
- **"剥洋葱"比喻**（微软研究院）：访谈像剥洋葱，你抢话或打断，可能永远停在第一二层；沉默能帮你到核心。

在文字/语音对话里，沉默的等价物是：**用户说完一段后，先反射、先追问一个更小的点，而不是急着给总结或换话题。** 给"补充"留出空间。

<a id="为什么"></a>
## 4. "为什么" vs "如何/什么"的边界

这是访谈文献里最显著的争议，化解如下：

- **行为改变场景**（心理咨询、教练、督促自己改变）：**避免"为什么"**。它容易激起防御和事后合理化。用替代句式：
  - "是什么让你……"
  - "这件事对你意味着什么"
  - "你当时是怎么考虑的"
- **意义理解场景**（自我回看、理解自己怎么变成现在这样）：**可有限度使用"为什么"**，但要配合非评判姿态和足够的信任基础。探索主观意义建构时，"为什么"是合理工具。

**自我采访默认走"意义理解"，但"如何/什么"几乎总是更安全、更能引出真实过程的选择。** 动机藏在行为描述里——让用户讲"当时怎么做的"，比问"当时为什么"更能挖到真东西。

<a id="追踪"></a>
## 5. 追踪问题与探测性问题

汪梅子的三层问题分类，对应访谈里两种关键的"接着问"：

- **追踪问题（follow-up）**：用户提到一个东西，你顺着往下问。比如用户说"我们当时考虑了三条路"，你追问"这三条分别是什么？最后是什么让你选了现在这条？"——抓住用户自己抛出的线头。
- **探测性问题（probes）**：控制深度和节奏。形式很灵活：
  - 沉默几秒等他补充
  - 一个点头、"嗯"、或者"比如？"
  - "您能具体说说吗？""那时你心里在想什么？"
  - ⚠️ 探测不宜过多，否则显得不礼貌、还会稀释效果。

追踪和探测的区别：追踪是"顺着内容往下走"，探测是"调节深度的快门"。两者经常配合。

<a id="错误"></a>
## 6. 五类常见错误

采访里最容易踩的坑，每一类都附了在自我采访中的表现：

1. **引导性提问**——问题里隐含了预期答案。
   - ❌ "很多人觉得这份工作没意义，你也这么觉得吧？"
   - ✅ 关注直接体验，保持客观不评判，不用双重否定。

2. **过度打断 / 急着填话**——抢走用户整理思路的时间，丢掉有价值的东西。
   - 自我采访里最常见：用户讲到一半停顿，你忍不住总结。**忍住，数到七。**

3. **问题过大过空**——用户无法聚焦，答得"辞不达意"。
   - ❌ "你这半年的成长是什么？"
   - ✅ 缩小到一个具体事件、一个瞬间——落到时间、地点、在场的人（5W2H 的 When/Where/Who），一落地，画面就出来了。

4. **忽视非语言 / 情绪信号**——文字访谈里表现为：用户突然变简短、改话题、用词变得回避，这些都是信号，可能触到了敏感区。别硬推，可以轻问"这个话题好像不太好聊，要换一个吗？"

5. **跳过准备直接开问**——即使是"采访自己"，也要先想清"我想通过这次访谈理解什么"。这就是 SKILL.md 里"启动三问"存在的理由。

<a id="关系"></a>
## 7. 关系管理：面子与双向价值

虽然是自我采访，"关系"依然存在——你和用户（他自己）之间要维持一种安全、平等、不被评判的氛围。

- **维护面子**：避免让用户感到被冒犯、被质疑、被定义。反射性倾听 + 肯定是维护面面的主力。
- **尊重社交权利**：知情权（让他知道访谈会走向哪）、公平对待（不预设"正确答案"）、边界（他说"这个先不聊"就停）。
- **双向价值**：访谈对他（用户自己）有什么价值，要让他感受到——不是你在榨取他的故事，而是你在帮他理清自己。启动时把"这次访谈能帮你做什么"讲清楚，全程让他感到"被认真倾听"本身就是回报。

<a id="探针"></a>
## 8. 间接探针：羡慕、逃避、时间去向

最重要的价值往往直接问不出来——直接问"你在乎什么"，得到的多是"应该"的答案（见前面"应该 vs 真正想要"）。三个间接信号能绕过理性包装：

- **羡慕**：羡慕别人身上的哪种特质？羡慕是"未活出的自己"的信号。追问一句"你身上其实也有它的影子吗"，常能打开一整段。
- **逃避**：你一直在逃避的事，暴露了你真正在意什么——怕搞砸的才是在乎的。比正面问"你在乎什么"诚实得多。
- **时间去向**：不听说重视什么，看时间实际花在哪。"你说最看重 X——过去一个月的周末，它们都去哪了？"和"言行落差"同族，但更温和：不带旁观者的审视感，只是把事实摆出来。

三个探针按从轻到重排序（羡慕最轻，时间去向最直接）。照常递回去、不判定——探针照见的东西，认不认由他，否认里也常有信息。

<a id="苏格拉底"></a>
## 9. 苏格拉底六步：观念辨析的追问链

用户抛出一个观点、信念或自我评价（"我觉得稳定最重要"），而你感觉它没被检验过时，沿这条链走，**一次一问**：

1. 明确边界："你说的'稳定'，具体指什么？"
2. 拆解前提："这个判断，是基于哪段经历？"
3. 检验逻辑："从那段经历到'稳定最重要'，中间是怎么推过来的？"
4. 换视角："有没有人处境相似，却得出相反的结论？"
5. 找例外："有没有哪一次，不稳定反而让你更好了？"
6. 回到本质："剥开这些，你真正想守住的到底是什么？"

访谈用法：不必走满六步——用户卡住或起防御时随时停，回到反射倾听。它和 SKILL.md 的"苏格拉底透镜"是同一个东西的两面：透镜说**何时**用，六步说**怎么**走。第 3、5 步最容易引防御，语气放软（"不知道这样理解对不对……"），递回去而不是逼到墙角。

## 一句话总结

这些技巧不是让你变得更"专业"的装饰，而是帮你做到一件具体的事：**让用户在安全、不被定义的氛围里，把自己讲得更深、更真。** 当你不知道该用什么技巧时，回到最朴素的两个——**开放式问题 + 反射性倾听**——它们几乎不会错。
