# 人物访谈报告（生成报告前读）

> 本文件由 SKILL.md 按需加载：只在用户点头生成报告时读（CHECKPOINT 见 SKILL.md「输出」指针）。平时不进上下文。

## 输出：人物访谈报告

**🔴 CHECKPOINT（生成前必停）：报告必须用户点头才生成。** 用户主动说"生成报告 / 总结一下 / 可以收尾了"（"可以收尾了"本身就是结束语义），或你主动提议"要不我把这次访谈整理成一份阶段性报告？"——**让他点头再做，不要自行生成。**

**报告 ≠ 结束。** 报告是阶段性总结：生成、确认之后，访谈照常继续——你回到提问循环接着问，直到用户说出结束语义（见「持续推进与停止条件」）；归档只发生在结束流程里，阶段性报告生成后不要问归档。提议报告后也不要停下等答复，循环不断。

**报告结构**（存为 `remeet-me/report.md`）：

```markdown
# 《[阶段]个人访谈报告》

## 一、阶段背景
时间范围 / 核心事件

## 二、人生主题
> 这是一个 ________ 的阶段。（一句话，来自用户自己的表达，不是你替他升华）

## 三、重要事件时间线
| 时间 | 事件 | 影响 |

## 四、分领域探索
每个探索过的领域写：发生了什么 → 当时感受 → 深层原因 → 认知变化

## 五、当前人物画像
- 当前状态：
- 核心需求：
- 核心价值 / 能力来源：
- 反复出现的矛盾：
- 这一阶段正在面对的课题：

## 六、留给未来自己的问题
不是目标清单，而是"未来继续观察什么"

## 七、纵向变化（仅当有历史归档时写；无历史则跳过）

- 主题迁移：各周期「人生主题」那句话排成时间线，看出阶段主题怎么迁移。这一列必须来自该期 report 的「人生主题」原句/用户原话；无 report 的期才允许 AI 自拟并标「（AI 提炼-可推翻）」。
- 原词跨周期归组：连续多个周期都出现的词/矛盾，标注"这是第 N 次出现"。**每次出现都要把它当时的语境/原话带一小段**，不能只堆一个词加序号——读的人（用户本人）多半已记不清，要让他看得懂每次分别是在说什么。序数冲突时标"计数待核"，不照抄单期自报的 ×n。
- 定向模块演变（若用户指定了某模块深读）：对该模块做更深的跨周期梳理

> 这一节是唯一允许做"归纳归并"的地方，所有归纳判断带"（AI 提炼，可推翻）"标注；对比的是用户自己当时说过的原话，不是你替他贴的标签。
```

**生成这一节之前（后台动作，不写进报告）**：先看 `记忆索引.md`——主题总表给主题迁移、反复浮现的词给原词归组、主线卡时间线给模块演变；索引没有的再定向读快照，不要重新全量读。所有 AI 归纳在报告里照旧标「（AI 提炼，可推翻）」。但**报告正文里不出现「索引 / 主线卡 / 散点 / 休眠 / GC」这些词**——它们是后台概念，读者只该看到内容。

**长跨度报告触发流程**：用户要覆盖多次快照的整体报告（"给我出这半年的报告"）→ 列出 `archive/` 日期范围内的快照，**每个配一句"这份里聊了什么"**（只给文件名他确认不了范围，见「引用历史时：自带内容，不给空指针」）→ 用户确认范围 → **优先从 `记忆索引.md` 取主题迁移 / 原词归组 / 主线时间线；索引没有的再逐份读快照**，读不下就分批 → 存为 `archive/` 内**独立文件**（以 `长跨度-` 开头，如 `长跨度-2026H1-report.md`；此类文件不算一期），不覆盖当前区 `report.md`。

**长跨度报告变体**（覆盖多次快照的整体报告，存为 `archive/` 内独立文件，见「读历史」节）：同七节骨架，但重心倒置——前六节压缩为逐周期速览（每周期一小块：主题一句话 + 画像要点），「纵向变化」升级为报告主体（主题迁移时间线、原词跨周期聚簇、模块演变逐条展开）。它几乎全是跨周期归纳，所以「（AI 提炼，可推翻）」标注**全文适用**，不只纵向节。**因为通篇都在回望过去，本变体对「自带内容，不给空指针」的要求最重**：每提一个往期词/主题，都要带上它当时的语境。它几乎就是为记不清过去的人写的——他只读这一份，前几份未必在手边。「人生主题」「当前人物画像」两块照常保留——下次新访谈的默认轻读靠它们把长跨度结论带进背景。

**生成前自检**：
- 有没有具体事件？（不能只有"你更成熟了"这种空话）
- **报告里提历史的地方，有没有自带内容？**（每一次提到往期的词/主题，都附了它当时的语境——不能让他靠回忆去补，见「引用历史时：自带内容，不给空指针」）
- 有没有背后原因和认知变化，而不只停留在表面？
- 有没有忍住鸡汤和心理诊断？允许"还没想清楚"留着？
- 每一句判断是不是都能在用户说过的话里找到出处？（推测性的观察要标注为推测）
- 用户读完应该觉得"这是我说过的话被理解后形成的东西"，而不是"AI 替我定义了我是谁"。
