# 理论锚点详解（按需查阅）

> SKILL.md 菜单里每个模块附的"理论锚点"是挖深方向的提示。这里放需要展开的锚点详解——访谈进入对应模块、想挖得更准时来翻。照旧：它们是你脑内的地图，不是要对用户背诵的名词。
>
> **它们是看素材的镜头，不是题库。**提问内容永远来自用户当下的原话（SKILL.md 的五类信号）；锚点只决定往哪个方向深挖。从这里取题去问，就滑回了"走问卷"的老路——那是这个 skill 明令禁止的。

## Ikigai：四圈、四区、三个误解

Ikigai（生き甲斐，iki=生命、kai=价值）日文原意比流行版朴实：**让你愿意每天起床的那个小小理由**——可以是一盆花、一段关系、一件小事，不必是惊天动地的天命。

### 四圈

你热爱的 / 你擅长的 / 世界需要的 / 能赚到钱的。四圈全交集的正中央 = 流行版 ikigai。

### 四区比中央更有用

多数人一时到不了中央，真正有诊断力的是两两交集的四个区——每区配一种典型体感：

| 区 | 交集 | 典型体感 |
|---|---|---|
| 热情 | 热爱+擅长 | 做得开心又拿手，收入常成问题 |
| 专业 | 擅长+赚钱 | 稳定有收入，做久了空虚 |
| 天职 | 赚钱+需要 | 有价值有钱，少了热爱 |
| 使命 | 需要+热爱 | 很有意义，收入偏薄 |

访谈用法：不追问"你的四圈交集是什么"（太空），而是问"你现在的工作更像四区里的哪一个？缺的那一圈是什么？"——用户几乎总能立刻认领一个区，缺口自己就浮出来了。

### 右边两圈要证据

"世界需要"和"能赚钱"是外部现实，脑内打勾不作数——你以为世界需要，可能只有你自己需要。这两圈要用行为证据验（与 techniques.md 的"时间去向"探针同族）。访谈里遇到用户对"被需要"的判断，可以轻轻要证据："这个需要，除了你自己觉得，还有什么地方能看到它？"

### 三个误解（访谈里尤其要防）

1. **不一定是工作或钱**——孩子、爱好、一段关系都可以是 ikigai。访谈别默认往工作上引。
2. **不必是宏大天命**——把热爱从"人生使命"还原成"做起来就忘了时间的小事"，反而容易找到。这条直接服务"允许平淡"原则：用户说"我就是喜欢每天傍晚散步"，那就是，不嫌小。
3. **不止一个、会变**——上次访谈的 ikigai 这次变了，不是背叛，是活的。跨周期对照时别拿旧结论当标尺。

### 边界

静态快照：它照出此刻的落点，不给路径；人也随时间移动，四圈会变——适合每个周期重新照一次，"圈的移动"本身就是纵向对比的素材。

## Oishi 三维度：幸福、意义、心理丰富性

三维度不必一致——**错配本身就是画像**。

| 模式 | 表现 | 访谈里像什么 |
|---|---|---|
| 高幸福 + 低意义 | 享受当下但缺方向感 | "日子挺舒服的，就是不知道图什么" |
| 高意义 + 低幸福 | "苦行僧"：有价值但不快乐 | "这事重要，但我已经很久没开心过了" |
| 高丰富 + 中幸福中意义 | 体验追求者：追新鲜、多视角，常被误判"不安分/不幸福" | 频繁跨界、总在换城市换赛道，旁人惋惜、他自己带劲 |

访谈用法：

- 三个维度各有一问：生活舒适愉悦吗 / 做的事有目的、有贡献吗 / 生活够新奇、视角常被刷新吗——**一次只问一个**，别连排成问卷。
- **叙事探索问题**："你人生中改变你看世界方式的经历是什么？"——直击心理丰富性，常能打开从未被问过的空间。负面经历也计入：它不美化痛苦，但承认"那段痛改变了你看世界的视角"——这是深挖痛处之后不鸡汤的意义重建出口。
- 第三模式是替"不安稳但活得浓"的人正名——别用"稳定下来"的预设去追他们。

防误用：这是透镜不是评分表。错配模式是**递回去的观察**，不是标签——禁说"你这是苦行僧模式"；可以说"听起来有价值感的事没给你多少愉悦，这个落差值得看看"。

## PERMA：五根柱子的落差

P 积极情绪 / E 投入 / R 人际 / M 意义 / A 成就——各有一问：

- P："最近什么时候让你觉得开心、愉悦？多久有一次？"
- E："做什么事的时候你会忘记时间？"（心流）
- R："你生命中最重要的三个人是谁？关系质量怎么样？"
- M："你正在做的事有什么意义？不做会怎样？"
- A："最近最有成就感的事是什么？在追一个什么样的目标？"

访谈用法：一次问一根柱子，别五连发。用户"有意义但没成就感"这类表述，是两根柱子间的错位——**追问落差本身**，落差里出画像。E 和 Ikigai 的热爱圈是同一片区域的两张地图，可互译。

不搬的：Profiler 问卷、GROW 目标设定、间隔重测——那是教练的量化体系；访谈要的是柱子间的落差，不是分数。

## 舒伯生涯彩虹图：角色与阶段

- **角色盘点**："现在同时背着哪些角色（子女/伴侣/父母/工作者/朋友/休闲者……）？哪个占了 80% 的精力？"
- **角色超载追击**："这种失衡是主动选择，还是被动陷入？"——主动/被动之分直击模式层（五层追问的第 4 层）。
- **阶段定位**："这个人生阶段的典型任务，和你实际在过的日子，偏差在哪？"
- **跨阶段**："上一阶段你完成了什么？下一个阶段你觉得需要准备什么？"——天然衔接报告的「留给未来自己的问题」。

## 人生平衡轮：迷茫期的鸟瞰快扫

适用场景：用户开场"感觉哪里不对但说不清"。一句话版：

> "生活的几大块——工作、身体、关系、钱、属于自己的时间——哪块现在最不像话？"

从最低那块切入深挖（情绪强度天然高，主题权重自动置顶）。维度间的关联是矛盾信号的矿：工作满分身体垫底式的"以命换事业"，直接递回去看。

防误用：**不做打分表、不画图、不走 8 维问卷**——那是教练的流程；访谈只要"哪块最低"这一个坐标。

## 组合逻辑（一句话）

平衡轮找广度（哪里不对）、PERMA 找落差（哪根柱子短）、舒伯找时间线（角色怎么演变）、Oishi 找盲区（三维错配）。递进着用，但都是透镜，不是流程。
